# Example data

`demo.mbox` is entirely fictional and deterministically generated by:

```bash
loopledger sample examples/demo.mbox --force
```

At `--as-of 2026-02-01`, it contains three overdue requests, one thread closed by a reply,
one FYI-only outbound message, and one automated receipt. This makes it useful for checking
positive, negative, and multi-turn behavior without exposing a real mailbox.

`state.example.json` demonstrates the versioned override format. IDs are stable for the same
messages and can be copied from `report.json`.
