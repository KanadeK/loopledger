# Changelog

All notable changes are documented here. This project follows
[Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-08-08

### Added

- Offline MBOX, Maildir, single-EML, and recursive EML-directory parsing.
- Message-ID/References thread reconstruction with a conservative subject-participant fallback.
- Explainable English and Chinese request scoring and automated-message filtering.
- Open, overdue, snoozed, ignored, and resolved loop handling.
- Standalone HTML, JSON, CSV, iCalendar, and SHA-256 manifest outputs.
- Deterministic fictional mailbox generator and 83-test cross-platform release gate.
- Bilingual documentation, GitHub Pages demo workflow, CI, CodeQL, and release packaging.
